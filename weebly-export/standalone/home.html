What we do

Code, compete, and have fun doing it.

We bring computer science to everyone at Dulles, and turn problem solving into something you'll want to do.

Regular meetings

Hands-on lessons that build on each other, from your first println to real algorithms.

Contests

Compete in UIL invitationals, Codeforces rounds and USACO, and earn points for every one.

Learn to code

Java for competitive programming, Python for data structures and AI/ML, and maybe some JavaScript later in the year.

Community

Meet people who like building things. Ask questions, pair up on problems, and learn together.
