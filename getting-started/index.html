Learn Java

The only links you need.

Java is the language we use at meetings and in UIL contests. Start with setup, then learn and practice.

1 · Set up

  • Java JDK The compiler and runtime. Install the latest LTS version. oracle.com
  • Apache NetBeans A beginner-friendly Java IDE, and the club's longtime pick. netbeans.apache.org
  • Eclipse IDE Another popular free IDE. Choose "Eclipse IDE for Java Developers". eclipse.org

2 · Learn

  • W3Schools Java Short, interactive lessons that cover all the basics. w3schools.com
  • Algorithms, 4th Ed. Sedgewick & Wayne's classic, with all code in Java. For after the basics. algs4.cs.princeton.edu
  • Algorithms, Part I Princeton's free course on data structures, sorting and searching. coursera.org
  • Algorithms, Part II The follow-up: graphs, strings and advanced algorithms. coursera.org

3 · Practice

  • CodingBat Java Bite-size problems with instant feedback. Nothing to install. codingbat.com
  • UIL Computer Science Official contest info, rules and practice materials. uiltexas.org

Prefer a book? Ask to borrow a copy of Big Java from one of our club sponsors. And if you get stuck on anything, ask an officer at the next meeting. That's what we're here for.
